# Personal-App

Aplicativo completo de gestão para Personal Trainer e alunos.

## Tecnologias
- **Framework**: Next.js 14 (App Router)
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS + Lucide Icons
- **Banco de Dados**: SQLite com Prisma ORM
- **Container**: Docker

## Executar Localmente
```bash
npm install
npm run dev
```

## Build de Produção
```bash
npm run build
npm start
```
